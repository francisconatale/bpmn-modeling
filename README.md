# BPMN Models

A collection of business process models created using BPMN 2.0 and [Camunda Modeler](https://docs.camunda.io/downloads/).

## Tools

* [Camunda Modeler](https://docs.camunda.io/downloads/)
* BPMN 2.0

## Usage

Download a `.bpmn` file and open it with Camunda Modeler to view or edit the process diagram.
